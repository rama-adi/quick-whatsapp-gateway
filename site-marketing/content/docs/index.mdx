WhatsApp Gateway connects linked WhatsApp devices to applications through an API,
a dashboard, webhooks, and realtime events. The WhatsApp Gateway documentation website explains how to host a gateway
installation and how its services work. People using an existing installation can find
pairing, messaging, organization, and integration guides under **Docs** in their
dashboard.

## What runs where

The **API** authenticates callers, owns shared WhatsApp application data in MySQL,
and coordinates gateways. The **gateway** owns live WhatsApp connections and
local SQLite device and journal state. The **web app** provides identity and the
dashboard. This **marketing and documentation site** runs independently with its own content and server bundle.

Read the subsystem pages for concrete contracts, failure behavior, known
limitations, and operational tradeoffs. The operator guides provide current deployment instructions.

## Compatibility and account risk

The gateway uses whatsmeow, an unofficial WhatsApp client library. WhatsApp controls protocol changes and account restrictions. The [outbound pipeline](/docs/architecture/outbound-pipeline) describes the supported send types and production dispatch behavior.
