          Change settings of a session. Only the fields you send change.


          `historySyncDays` sets how many days of chat history are imported the
          next time the phone is linked or relinked. It does not re-import
          history for a device that is already linked.


          Requires `manage` capability. Returns the updated session.


          Errors: `validation_error` (400) for a value outside 0 and the
          deployment maximum, `not_found` (404), `unauthorized` (401),
          `forbidden` (403).
