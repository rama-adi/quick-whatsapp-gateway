      - content: >-
          Unlink the device on WhatsApp and clear the attached WhatsApp number;
          the session's desired state becomes `stop`.


          Unlinking is a request to WhatsApp: a stopped session is connected for
          the duration of the call. When WhatsApp does not confirm the unlink,
          the call fails and the device stays linked, so you can retry.


          To delete session metadata, call `DELETE /sessions/{session}`.


          Response is the session row; repeated calls are idempotent when
          already logged out.


          Errors: `not_found` (404), `gateway_unavailable` (503), `unauthorized`
          (401), `forbidden` (403).
