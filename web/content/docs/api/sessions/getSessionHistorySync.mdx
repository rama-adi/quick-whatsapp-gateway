      - content: >-
          Show how the import of chat history from the phone is going. When a
          device is linked or relinked, the phone sends the chat history it
          still has; the gateway imports up to `historySyncDays` days of it.


          The response has the session's import setting, whether the session was
          relinked to a different phone number, and the latest import run. `run`
          is absent until the phone sends history. While `run.status` is
          `running`, compare `batchesApplied` with `batches` and use `progress`
          (percent reported by the phone). `run.stalled` turns true when a
          running import has had no activity for 10 minutes.


          Imported messages are stored like received messages with `origin` set
          to `history`. They do not trigger `message` webhooks; subscribe to
          `history.sync` (progress) or `history.batch` (the imported data,
          opt-in) instead.


          Requires `read` capability. Errors: `not_found` (404), `unauthorized`
          (401), `forbidden` (403).
