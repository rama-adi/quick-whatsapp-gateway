      - content: >-
          Returns an activity summary for the caller's organization over a
          recent window: messages received and sent, active chats, failed sends,
          and webhook delivery outcomes. Each count is returned as a window
          total and as a per-bucket series for charts. Requires the `read`
          capability.


          **Buckets.** `range=24h` returns 24 hourly buckets; `7d`, `14d` and
          `30d` return 7, 14 or 30 daily buckets. Buckets are aligned to the
          `tz` time zone and listed in `buckets` as epoch-millisecond start
          times, oldest first. The last bucket contains the current moment, so
          it is partial. Every series has one entry per bucket, and buckets
          without activity are 0.


          **What is counted.** Messages are bucketed by their WhatsApp
          timestamp. Failed sends and webhook deliveries are bucketed by when
          they were created, using their current status. `hasSentMessage` and
          `retentionDays` describe the organization and do not depend on the
          window. Session states, API keys and webhook configuration are not
          included; use `GET /sessions` and `GET /webhooks` for those.


          Errors: `validation_error` if `range` or `tz` is invalid; `not_found`
          if `session` is not owned by the caller's organization; `forbidden` if
          the caller lacks the `read` capability.
