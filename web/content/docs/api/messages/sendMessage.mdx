          Send one message or one grouped media album from the session.


          Use `type` in the body to select a supported payload (`text`, `poll`,
          `location`, `contact`, `buttons`, `list`).


          Buttons use native-flow quick replies; lists use legacy ListMessage.
          Both are experimental, including for group JIDs. A send
          acknowledgement does not guarantee client rendering. WhatsApp may
          reject a list with 405; this returns not_implemented and is not
          retried.


          Default mode is synchronous and returns 200 after a validated send.
          Set `async=true` for queued sends that return 202. A terminal replay
          also returns 200, including status=unknown when a remote effect may
          have committed.

          Idempotency is enabled with `Idempotency-Key`; replay returns the
          current durable result in the original session. Optional expiresAt is
          an absolute UTC epoch millisecond frozen by the first accepted row. No
          new WhatsApp dispatch starts at or after that deadline.


          Errors: `validation_error`, `not_found`, `rate_limited`, and
          `not_implemented` for unsupported types.
