This guide gets you to a running system and a signed-in account. The gateway is
the service that holds the WhatsApp connection and serves the API; the dashboard
is the web app where you sign in and manage things.

## Open your dashboard

Use the dashboard URL provided by the person hosting your gateway. You also need
the public API URL when calling the gateway from your own code.

## Create your account

Open the dashboard and sign up with an email and password. If registration is
closed, ask your gateway operator to create an account for you. New accounts
receive ordinary user access and a personal organization.

## Your personal organization

Every resource in the gateway — a WhatsApp number, an API key, a webhook —
belongs to an **organization** (a container that owns resources and can have
several members), not to you directly. So when you sign up, the dashboard
automatically creates a **personal organization** for you and makes you its
owner.

For solo use you never think about this: your personal org is just "your stuff",
and every number and key you create lands in it. It matters once you want to
**share** a connection — sharing means inviting someone into the org that owns it.
See [organizations](/docs/guides/organizations).
